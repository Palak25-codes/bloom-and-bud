# 🌸 Bloom & Bud – Flower Shop Website

Bloom & Bud is a responsive flower shop website designed to showcase beautiful floral arrangements and make browsing flowers for different occasions simple and enjoyable.

The website features an elegant design, floral imagery, smooth navigation and interactive elements to create a pleasant browsing experience.

## ✨ Features

- **Responsive Design:** Adapts to different screen sizes, including desktops, tablets and mobile devices.
- **Navigation Menu:** Easy navigation between different sections of the website.
- **Mobile Navigation:** Interactive hamburger menu for smaller screens.
- **Flower Collections:** Displays floral arrangements and bouquet collections.
- **Occasion-Based Browsing:** Showcases flowers for occasions such as birthdays and anniversaries.
- **Contact Section:** Includes a contact form with interactive feedback.
- **Interactive Elements:** JavaScript-powered navigation and form interactions.

## 🛠️ Technologies Used

- **HTML5** – Structure and content of the website.
- **CSS3** – Styling, layouts, animations and responsive design.
- **JavaScript** – Mobile navigation, active navigation highlighting and contact form interactions.

## ⚙️ JavaScript Functionality

JavaScript is used to make the website interactive.

Some of its main functionalities include:

- Toggles the mobile navigation menu.
- Updates the navigation button's `aria-expanded` attribute.
- Closes the mobile menu when a navigation link is clicked.
- Highlights the active navigation link.
- Handles contact form submission on the frontend.
- Displays a success message and resets the form.

**Note:** The contact form currently provides frontend feedback only. It does not send messages to a backend or email service.

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Palak25-codes/bloom-and-bud.git
   ```

2. Open the project folder:

   ```bash
   cd bloom-and-bud
   ```

3. Open `index.html` in your browser.

No additional installations or dependencies are required.
